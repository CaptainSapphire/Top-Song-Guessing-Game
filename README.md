# Top Song Guessing Game
Hello! Welcome to the top song guessing game, a simple project involving data scraping with python!

## Inspiration
This was inspired by the [Geeksforgeeks Quote Guessing Game Project](https://www.geeksforgeeks.org/python/quote-guessing-game-using-web-scraping-in-python/). <br>

## Installations
You'll need to have [BeautifulSoup](https://pypi.org/project/beautifulsoup4/) for webscraping, and python. 
You can Beautiful Soup with this command in your command prompt:
```
pip install beautifulsoup4
```
[See here for as tutorial, if you're having trouble with Beautiful Soup.](https://pytutorial.com/install-beautifulsoup-in-python-step-by-step/) <br><br>

## What I used
I used Visual Studio Code as my IDE, but you can use Pycharm (The jetbrains IDE) or any that runs on your respective system. 

## Of note
```os.system('cls')``` is the windows command, but if you use MacOS/Linux, use ```os.system('clear')```. It's not necessary for the function of the program, but I like how it looks. 

## What it does
It will take the data from the number one spot from the [Billboard Hot 100](https://www.billboard.com/charts/hot-100/) and stores it as text, and then prompts the user to guess the top song within 5 guesses. It is relatively simple, but I enjoyed the process.
